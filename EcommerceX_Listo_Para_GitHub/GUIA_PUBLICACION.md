# Guía para presentar E-Commerce X al profesor

**GitHub:** https://github.com/taekcidio/ecommerce-x-retencion

**Versión:** ecommerce-x-retencion (2).zip incluida originalmente en trabaajo.zip.

## Subir actualización
1. Extrae el ZIP de entrega.
2. En el repositorio, entra a **Add file → Upload files**.
3. Arrastra el contenido de la carpeta descomprimida, no la carpeta contenedora ni un ZIP.
4. Confirma que `app/pages/dashboard.py`, `analisis/tablero.py`, `analisis/modelo.py`, `.streamlit/config.toml` y `requirements.txt` estén en las rutas mostradas.
5. Si GitHub no permite sustituir los archivos existentes por la interfaz web, usa GitHub Desktop para actualizar el repositorio.
6. Confirma cambios en `main`.

## Publicar dashboard
- https://share.streamlit.io → Create app → Yup, I have an app.
- Repository: `taekcidio/ecommerce-x-retencion`
- Branch: `main`
- Main file path: `app/pages/dashboard.py`
- Deploy; revisa gráficas, filtros, pestañas y modelo predictivo.

## Evidencias sugeridas
- Captura de portada del dashboard e indicadores KPI.
- Captura de tendencias y filtros.
- Captura de segmentación y factores de abandono.
- Captura del modelo predictivo y recomendaciones.
- Enlace al dashboard y al repositorio en el informe del curso.
